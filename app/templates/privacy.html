Privacy Policy & Data Custody

Effective Date: October 19, 2026 • Version 1.0 • Sovereign BYOK Architecture

shield 1. The Zero Data Leakage Guarantee

PatchPilot is architected from the ground up as a Bring Your Own Key (BYOK) review engine. Unlike conventional SaaS review bots:

  • We never train models on your code. Neither PatchPilot nor Noventra retains, aggregates, or trains any machine learning model on your repository code, commits, or pull requests.
  • Ephemeral In-Memory Processing: Pull request diffs are retrieved strictly on-demand in memory, processed through your designated model endpoint, and immediately discarded upon review submission. Diffs are never written to disk or persistent databases.
  • Air-Gapped & Self-Hosted Support: For organizations with strict compliance, PatchPilot can be self-hosted via Docker or Kubernetes with a local, air-gapped Ollama instance.

lock 2. Cryptographic Security of Your API Keys

When you configure your provider keys (Google Gemini, OpenAI, Claude via OpenRouter, Groq, xAI Grok) in the PatchPilot BYOK Vault:

AES-256-GCM Encryption Specification:

Every key is encrypted at rest using an authenticated 256-bit Galois/Counter Mode cipher. Each entry generates a unique cryptographically random 96-bit initialization vector (nonce) and authentication tag to guarantee confidentiality and prevent tampering.

database 3. Information We Collect and Process

We collect only the bare minimum data necessary to route webhooks and authenticate your session:

Identity & Account GitHub username, avatar URL, and user ID for authentication session issuance.
App Installation ID GitHub App installation IDs used strictly to route review webhooks to your vault config.
Review Guidelines Custom policy prompt guidelines saved by you in your BYOK vault to tailor code reviews.
Encrypted API Keys Encrypted ciphertext of your LLM provider key, stored securely in PostgreSQL/SQLite.

cloud_sync 4. Direct Provider Communication

During PR reviews, PatchPilot dispatches the code diff directly from the server to your selected provider using your encrypted credentials. Your data is subject to the data protection agreement of your chosen AI provider (e.g., Google Cloud Vertex/Gemini Enterprise API terms, OpenAI API zero-retention policy). PatchPilot never intermediates or proxies your requests through third-party telemetry aggregators.

delete_forever 5. Data Deletion and Revocation

You maintain unconditional control over your data:

  • You can delete or overwrite your encrypted vault credentials at any time in the BYOK Vault Dashboard.
  • Uninstalling the GitHub App instantly terminates webhook access to all your repositories.
  • To request a complete database purge of all records associated with your GitHub owner name, submit an issue or contact our security desk.
